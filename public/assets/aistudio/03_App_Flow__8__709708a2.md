## 2. Guards & Redirects

| Situation | Behavior |
|-----------|----------|
| Session nahi, protected route | → `/login` (Master Password form) |
| Session hai, locked (reload/idle/Lock Screen) | → `/login` (PIN pad); unlock ke baad original route |
| `/login` par unlocked owner | → `/dashboard` |
| Session expire | Toast "Session expire ho gaya" → `/login` |
| `/` par session | "Enter" → `/dashboard` |
| Panic active | App shell par red banner "Panic mode ON — mic aur commands band"; Talk/Control disabled; Resume `/safety` par |

## 3. Auth Flow

1. **Landing** → "Enter" / "Talk to Zara" → `/login`.
2. **Login:** default PIN pad (agar device par session hai). "Switch to Master Password" → email + password form.
3. **Master Password success:** agar PIN set nahi → "Set your 6-digit PIN" modal → unlock → `/dashboard`.
4. **PIN success:** `sessionStorage` unlock flag → `/dashboard`.
5. **PIN fail:** shake + "Galat PIN (N attempts baqi)"; 5 fail par "15 minute ke liye lock" countdown; sirf Master Password ka raasta khula.
6. **Loading** (button spinner), **network error** ("Connection masla. Dobara koshish karein.").
7. **Logout / Lock Session** (Settings, sidebar) → `/login`.
8. Biometrics/Passkey button: disabled, "Coming later" tooltip.

## 4. Per-Screen Flow

### 4.1 Landing Page (`/`)
- Sections: hero (orb), features (6), sample conversation, privacy, CTA, footer. Sab static.
- Actions: Enter / Talk to Zara → login (ya dashboard).
- States: sirf static; fonts load na hon to fallback.

### 4.2 Owner Login (`/login`)
- PIN pad (0–9, CLEAR, backspace), "Unlock Zara", "Switch to Master Password".
- States: idle, typing (dots), verifying, wrong PIN, locked (countdown), network error, success.

### 4.3 Dashboard Home (`/dashboard`)
- Greeting + mood chip (latest `emotion_logs`), voice orb → `/talk`.
- Quick action chips ("Open Chrome", "Volume 30%" …): `laptop_command` bhejti hain (ya Zara ko text prompt).
- **Direct Actions** cards: Open App, Take Screenshot, Play Music (`media_control`), Set Reminder (modal).
- **Laptop Telemetry:** battery, CPU, temp, volume, brightness sliders (live), Lock/Focus/Sleep buttons.
- **Today's Schedule:** reminders + prayer times; checkbox complete.
- **Recent Conversations (3):** → `/history/:id`.
- States: laptop offline (telemetry card "Offline"), no reminders ("Aaj koi kaam nahi"), no conversations ("No memories yet. Say hello to Zara."), loading skeletons.

### 4.4 Live Voice Conversation (`/talk`)
1. Page open → mic permission prompt (agar pehli baar).
2. Orb tap / "Talk" → session start (`conversation_sessions` insert).
3. States: **idle → connecting → listening → thinking → speaking → (loop)**; **muted**; **error + retry**.
4. User bolta hai → transcript bubble; Zara ka jawab (RTL Urdu + English toggle); emotion chip update.
5. Tool call (laptop command): side panel "Zara ne kiya" mein live item (queued → running → done/failed/blocked).
6. Risky command: **Confirm modal** (Section 6).
7. Controls: Mute mic, Tap to Interrupt, Pitch/speed quick chip, text input send, Replay (agar `audio_path`), **End** → session ended, summary save → `/dashboard` ya `/history/:id`.
8. Edge: mic denied → "Mic ki ijazat chahiye" + steps; panic/mic disabled → blocked banner; Gemini disconnect → auto-retry 3 bar phir error.

### 4.5 Conversation History (`/history`, `/history/:sessionId`)
- List grouped (Today, Yesterday, This Week…); search; filters: All Logs, Today, Yesterday, This Week, Emotion (Playful/Caring…), Laptop Actions Only, Urdu Transcripts.
- Detail: transcript, audio scrubber (agar mojood), actions performed, **Continue this chat** (→ `/talk` naya session, purana summary context), **Export** (PDF / TXT), Delete (confirm).
- States: empty ("No memories yet. Say hello to Zara."), loading, not found.

### 4.6 Emotions & Mood Center (`/emotions`)
- Hero: current mood (latest log); Mirror mode toggle; Tone preset (Natural Auto / Urdu Poetic / Executive).
- 8 emotion cards: intensity slider (autosave debounce), **Preview Voice** (TTS sample).
- 7-Day Resonance Wave (`get_resonance_wave`), Real-time Logs list (latest 20).
- States: no logs ("Abhi koi mood data nahi"), save success toast.

### 4.7 Personality Studio (`/personality`)
- Identity (name, nickname chips), 7 trait sliders, flirt level segmented (Off/Light/Playful/Romantic) + note "Romantic aur sweet, kabhi explicit nahi", language style, dialect, formality, directive tags, custom instructions.
- **Persona Sandbox:** type → sample reply (preview call), mic button → `/talk`.
- Actions: **Save Persona Profile**, **Reset to Default** (confirm). Unsaved changes warning.

### 4.8 Voice Studio (`/voice-studio`)
- 4 voice cards (select, sample play); sliders (speed, pitch, warmth, expressiveness, pause); accent mode; wake word calibration (UI save only; **Test Mic Trigger** = mic level meter); Playground (text → synthesize/play), **Export WAV**.
- States: provider not connected ("Provider connect nahi — Settings"), synthesizing spinner, error.

### 4.9 Laptop Control Center (`/control`)
- Device header (name, OS, ping, uptime), telemetry tiles.
- Controls: volume slider, mute, brightness, night shift, lock, sleep, screenshot (preview result), focus mode.
- Running apps list (+ Close), "Open app" input, voice directive chips (click = bhejo).
- **Restricted System Actions:** shutdown, restart (confirmation: PIN), "Hardware Daemon Override" = panic link.
- States: **offline**, command pending/running/done/blocked (toast + badge), awaiting confirmation (modal).
- Later items (Wi-Fi/Bluetooth/clipboard/speedtest) disabled "Coming later" ya hide.

### 4.10 File & App Finder (`/files`)
- Search (text/mic), tabs (All Files, Applications, Recent, Starred/Vault), category chips.
- Result row actions: Open (`open_file`/`open_app`), Reveal, Rename, Star (DB), Trash (confirm; 10MB+ par PIN).
- Detail panel: size, permissions, checksum, Zara's note.
- Search: pehle `files_index` mein; na mile to `search_files` command (agent live search) → results index mein.
- States: offline, loading, no results ("Zara ko woh nahi mila. Doosra naam try karein?"), permission needed.

### 4.11 Automations & Routines (`/automations`)
- Tabs: Custom Voice Commands, Daily Routines & Modes, Hardware Event Triggers.
- Cards: toggle enable, **Run** (live), copy, edit, delete. **Run Dry Test** (steps validate + classify, execute nahi).
- **New Automation** → Visual Builder (trigger, steps add/reorder, confirmation toggle, save).
- Step validation: sirf catalog `command_type`; unknown ho to error.
- States: empty ("Abhi koi routine nahi. Zara ko kuch naya sikhayein."), run result toast, blocked step details.

### 4.12 Reminders, Timers & Prayer Times (`/reminders`)
- Prayer card (5 times, next countdown, per-prayer alert toggle, azaan toggle); **Sync Prayer Almanac** (recompute/cache).
- Tabs: Active Reminders, Countdown Timers, Alarms, Completed/Archived; category filter.
- **Add Reminder** modal (title, date/time, repeat, category, notify mode).
- Complete checkbox, edit, delete; timer circular countdown.
- First run: "Apna shehar chunein" prayer setup modal.
- States: empty per tab, notification permission prompt, fired reminder toast + sound (in-app).

### 4.13 Memory Vault (`/memory`)
- Filters: All Nodes, Personal, Work & Code, Relationship, Dates, Habits; search.
- Add manual memory modal (text, category), edit, delete, pin; **Export (.json)**.
- **Purge All:** modal 1 ("Erase N nodes") → PIN → success state "Vault Memory Completely Purged".
- Auto-learn toggle. States: empty ("Zara ne abhi kuch yaad nahi kiya").

### 4.14 Safety, Permissions & Activity Log (`/safety`)
- Mic master switch, **Emergency Panic Kill-Switch** (confirm → `panic_stop`; resume PIN se).
- Safety level selector (Relaxed / Prompt On Risk / Restricted).
- Permissions list: toggle + mode dropdown (Allow / Voice confirm / PIN required / Deny) + risk badge.
- Ask-Before rules toggles (aur threshold edit: 10MB).
- Voiceprint card: "Coming later" (disabled).
- **Ledger:** filters (All, Executed, Blocked, Awaiting Confirmation), date filter, pagination, row expand (detail, verified_by, hash), **Export CSV**; Realtime se naye rows.
- Awaiting confirmation row par **Approve / Reject** buttons.
- States: empty log, loading, export success.

### 4.15 Settings (`/settings`)
- Left section nav: AI & API Engines, Speech & Wake Word, Owner & Biometrics, Persona & Aesthetics, Data & Local Storage, Session & Lifecycle.
- AI & API: provider status (Gemini, ElevenLabs), **Test Ping**, temperature slider; Whisper local = Later. **API key fields nahi** — note "Keys Cloudflare secrets mein hain".
- Speech: wake phrase mode, sensitivity, mic device (browser list), language mode.
- Owner: Change Master PIN (current → new → confirm), auto-lock minutes, Biometrics/Voiceprint = Later.
- Appearance: accent tint, Urdu font.
- Data: **Export Backup (JSON)**, Restore (Later/validate JSON), Delete All Data (double confirm + PIN), Check Updates (hide).
- **Lock Session**, version.
- Save Changes / Reset Defaults (confirm). Unsaved changes warning.

## 5. Laptop Command Flow

1. Trigger: voice tool call, UI button, ya automation.
2. Client `insert laptop_commands {device_id, command_type, params, source}`.
3. DB trigger → `queued` | `awaiting_confirmation` | `blocked` (+ ledger row).
4. `queued` → Agent `running` → `done` | `failed` (+ result, ledger).
5. UI Realtime se status/result dikhata hai; voice session mein Gemini ko tool response.
6. Timeout: 30s mein agent claim na kare → UI "Laptop jawab nahi de raha" (command `queued` hi rehta hai; user cancel kar sakta hai).

## 6. Confirmation Flow

| Required method | UI | Backend |
|-----------------|----|---------|
| `voice` | Modal: command summary + "Haan / Nahi" (voice session mein bol kar bhi) | `confirm_laptop_command(id,'voice')` |
| `manual` | Modal + Approve/Reject | `confirm_laptop_command(id,'manual')` |
| `pin` | Modal + PIN pad | `confirm_laptop_command(id,'pin',pin)` |

Reject/cancel → `cancel_laptop_command` → `cancelled` + ledger. Modal 60s mein expire → cancelled.

## 7. Panic Flow
Safety/Control "Panic" → confirm → `panic_stop()` → mic off, queue cancelled, red banner → resume sirf `/safety` par PIN se (`panic_resume`).

## 8. Common States (har page par)

| State | Treatment |
|-------|-----------|
| Loading | Skeleton glass cards (spinner nahi) |
| Empty | Icon + warm Roman Urdu/English line + primary action |
| Error | Inline error card + "Dobara koshish karein"; toast for actions |
| Success | Toast (3s), button state |
| Offline laptop | Badge "Offline"; laptop-dependent controls disabled |
| Realtime reconnecting | Chhota top-bar indicator |
| Confirm destructive | Centered modal (mobile: bottom sheet) |

## 9. Forms Validation

| Form | Rules |
|------|-------|
| Master Password | valid email, password required |
| PIN | exactly 6 digits |
| Reminder | title 1–120 chars, `due_at` future (alarm/timer) |
| Memory | content 1–1000 chars |
| Automation | name required, ≥1 step, trigger required |
| Persona custom instructions | ≤ 4000 chars |
| File rename | no `/ \ :` characters |
