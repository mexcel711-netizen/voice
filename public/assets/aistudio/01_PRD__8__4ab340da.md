# 01_PRD.md — Zara: Personal AI Voice Assistant (Product Requirements)

## 1. Purpose & Goals

**Zara** ek personal AI voice assistant hai jo sirf **owner (aap)** ke liye hai. Website uska control center hai: aap Zara se realistic **female Urdu voice** mein baat karte hain, wo jazbaat dikhati hai, playful/romantic (explicit nahi) personality rakhti hai, aap ko yaad rakhti hai, aur laptop ko voice se control karti hai.

**Goals**
1. Natural, realtime Urdu/English/Roman Urdu voice conversation.
2. Emotions aur customizable personality (flirty-but-sweet, caring, playful).
3. Laptop control (apps, volume, brightness, screenshot, files, power) **safety guardrails ke saath**.
4. Memory, reminders, prayer times, automations.
5. Privacy: sirf owner, har risky action par confirmation, poora activity ledger.

**Success criteria:** owner login ke baad Zara se baat ho sake, ek voice command (e.g. "Chrome kholo") laptop par execute ho, risky command par confirmation aaye, har action log mein dikhe.

## 2. Target Users & Roles

| Role | Kaun | Access |
|------|------|--------|
| **Visitor** | Koi bhi bina login | Sirf Landing Page (`/`) |
| **Owner** | Aap (single user) | Poori app (13 screens) |
| **Agent** | Laptop par Zara Local Agent (software identity) | Sirf apne device ke commands/telemetry (Schema file dekhein) |

Koi Admin panel nahi. Koi multi-user, signup ya payment nahi.

## 3. Product Architecture (Bunyadi Samajh)

Website **browser mein chalti hai**, aur browser laptop ko direct control nahi kar sakta. Isliye 3 hisse hain:

| Hissa | Kya | Kaun banata hai |
|-------|-----|-----------------|
| **Zara Web App** | React website (UI + voice + settings + dashboard) | **Google AI Studio** (ye 6 files) |
| **Supabase + Cloudflare** | Database, Auth, Realtime, secure AI endpoints | ChatGPT (Supabase) + Cloudflare |
| **Zara Local Agent** | Laptop par chalne wali chhoti Python app jo commands execute karti hai | **Alag deliverable, website ke baad** (Claude/ChatGPT se) |

Website commands `laptop_commands` table mein likhti hai; Local Agent unhein Realtime se le kar chalata hai aur natija wapas likhta hai. **Local Agent ke baghair Laptop Control, File Finder aur laptop telemetry kaam nahi karenge**, lekin baqi website (voice chat, memory, reminders, personality, wagera) chalegi.

## 5. Features & Requirements

Priority: **MVP** = pehli build mein poora kaam kare. **Later** = UI maujood rahe lekin disabled / "Coming later" label ke saath.

### 5.1 Auth & App Lock — MVP
- Owner Supabase Auth se login (Master Password). Signup nahi.
- 6-digit PIN pad se quick unlock; 5 galat attempts par 15 min lock.
- Idle auto-lock (default 15 min), "Lock Screen" / "Lock Session".
- Biometrics (Touch ID/Windows Hello) aur Voiceprint — **Later**.

### 5.2 Live Voice Conversation — MVP
- Mic se realtime baat (Gemini Live), Urdu/English/Roman Urdu mix, beech mein interrupt.
- Live transcript (Urdu RTL Nastaliq + Roman + English toggle), emotion chip, status (Listening/Thinking/Speaking).
- Controls: mute, interrupt, text input fallback, end session, replay (agar audio saved ho).
- Zara tools use kar sakti hai: laptop command bhejna, yaad rakhna, emotion report, reminder banana.
- **Wake word ("Hey Zara")**: MVP mein sirf setting save hoti hai; asal detection **Later** (Local Agent/on-device). MVP mein orb tap ya push-to-talk.

### 5.3 Emotions & Personality — MVP
- 8 emotions (happy, sad, angry, surprised, shy, laughing, caring, teasing) ki intensity; "Preview Voice".
- Mirror mode: user ke mood ke mutabiq jawab.
- Tone presets: Natural Auto, Urdu Poetic, Executive.
- Personality: traits sliders, flirt level (Off/Light/Playful/Romantic — **kabhi explicit nahi**), nickname (Boss/Jaan/Sartaj/Sir), language style, dialect, custom instructions, sandbox preview.

### 5.4 Voice Studio — MVP
- 4 female Urdu voice presets, speed/pitch/warmth/expressiveness/pause, accent mode, test box (type → play), Export WAV.
- Provider: Gemini Live voice (default); ElevenLabs optional (server key hone par).

### 5.5 Laptop Control & Files — MVP (Local Agent ke saath)
- Commands: open/close app, running apps, volume, mute, brightness, night shift, focus mode, lock, sleep, restart, shutdown, screenshot, open URL, media control, files search/open/reveal/rename/trash, terminal.
- Live telemetry: battery, CPU, temperature, Wi-Fi, volume, brightness, uptime.
- File & App Finder: agent ka bheja hua index search/filter, star, open, reveal, rename, trash.
- Bluetooth/Wi-Fi toggles, clipboard, speedtest, Dolby/True Tone jaisi cheezen — **Later** (UI mein hide ya disabled).

### 5.6 Safety — MVP
- Master mic switch, **Panic kill-switch**.
- 8 permission rules (risk label + mode: allow / voice confirm / PIN required / deny).
- "Ask before doing" rules (10MB+ files delete, outgoing messages, dangerous terminal, secrets/.env).
- Safety level: Relaxed / Prompt on Risk / Restricted.
- **Activity Ledger**: har command ka append-only, hash-chained log; filter + CSV export.
- Voiceprint ("sirf meri awaaz") — **Later**.

### 5.7 Memory Vault — MVP
- Zara ki yaadein: category filter, search, manual add, edit, delete, pin, export (.json), "Purge All" (double confirmation).
- Auto-learning toggle. Episodic vs Semantic type.

### 5.8 Automations — MVP
- Custom voice commands (trigger phrase → steps), time routines, hardware triggers (e.g. charger connected).
- Visual builder (steps reorder), "Run Dry Test", enable/disable, duplicate, delete.
- Steps sirf allowed `command_type` se; confirmation rules wahi lagte hain.

### 5.9 Reminders, Timers & Prayer Times — MVP
- Reminders/timers/alarms (repeat, category, voice-created).
- Namaz ke auqaat (city/location setting se), next prayer countdown, per-prayer alert, azaan toggle.
- Firing: web app khuli ho to in-app/browser notification; **Local Agent** ho to laptop notification bhi.

### 5.11 Conversation History — MVP
- Search, filters (date, emotion, laptop actions, Urdu transcripts), session detail, audio replay (agar saved), "Continue this chat", export PDF/TXT, delete.

### 5.10 Settings — MVP
- Provider status (Gemini, ElevenLabs): connected/error + test ping. **API keys UI mein store/show nahi hotin** (Cloudflare secrets).
- Wake phrase mode, sensitivity, mic device, language mode.
- PIN change, auto-lock timeout. Appearance (accent tint, Urdu font).
- Data: export backup (JSON), delete all data (double confirm). Local Whisper — **Later**.

## 6. Business Rules

1. Sirf ek owner; signups band.
2. Risky command **server-side (database trigger)** se classify hoti hai; UI ya AI usay bypass nahi kar sakta.
3. `critical` commands (power) hamesha PIN maangti hain. Dangerous terminal patterns aur secrets access PIN ke baghair nahi.
4. Panic active ya mic disabled ho to voice-sourced commands `blocked`.
5. Har command (executed/blocked/failed) ka ledger entry banta hai; ledger edit/delete nahi hota.
6. Secrets (Gemini/ElevenLabs keys, service role) frontend, repo ya database mein nahi.
7. Audio default mein save nahi hota (`store_audio=false`).
8. Flirty content romantic/playful rahe, explicit/adult kabhi nahi (system prompt mein hard rule).
9. Zara kabhi data/files delete ya message bhejne ka kaam bina confirmation ke nahi karegi.

## 7. Non-Functional Requirements

- **Latency:** voice response shuru hone mein ~1–2 sec (network par munhasir); command dispatch UI mein <1s dikhe.
- **Security:** RLS har table par, HTTPS only, CSP, no secrets in bundle.
- **Privacy:** data sirf owner ke Supabase project mein; mic permission explicit; mic state hamesha top bar mein dikhe.
- **Languages:** UI English; Urdu RTL Nastaliq support (line-height ≥ 2.0×).
- **Responsive:** Stitch design desktop-first hai (neeche scope dekhein).
- **Accessibility:** keyboard nav, focus ring, labels, contrast; reduced-motion respect.
- **Reliability:** Realtime disconnect par auto-reconnect aur "Laptop offline" state.

## 8. Scope

**In scope (AI Studio build):** 15 screens ka React + TS frontend (Stitch Zip ke mutabiq), Supabase-ready services, Cloudflare Pages Functions ke liye endpoints ka code (`/functions/api/*`), types, env handling.

**Out of scope (is build mein nahi):** Zara Local Agent (Python), Supabase project/DB creation, asal API keys, voiceprint, biometrics/passkeys, on-device Whisper, wake-word detection, messaging (email/WhatsApp), Bluetooth/Wi-Fi/clipboard control, mobile-optimized layouts.
